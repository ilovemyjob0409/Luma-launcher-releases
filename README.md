# Luma launcher

一款致敬 [Folio](https://github.com/McCal-Codes/folio) 的 Android 桌面啟動器：首頁、Dock、資料夾、控制中心和通知中心，都換成會折射背景的 liquid glass（液態玻璃）介面。

📖 **[使用說明書](MANUAL.md)**：安裝、權限、桌面操作、Launcher 設定、懸浮狀態列（含 Good Lock QuickStar 設定）和常見問題。

## 下載安裝

1. 下載這裡的 `Luma-launcher-*.apk`（只會有一個，就是最新版）。
2. 安裝時如果手機詢問，允許瀏覽器或檔案管理員「安裝不明應用程式」。
3. 打開 Luma，依畫面設為預設桌面。

需要 Android 12 以上。

## 更新

裝好之後，Luma 每天會自動檢查這裡有沒有新版，有的話會通知你。也可以到「設定 › 軟體更新」自己檢查，按一下就能更新，桌面和設定都會保留。

每個更新在安裝前都會核對雜湊值（`SHA256SUMS.txt`）和簽名，只有 Luma 自己簽出的版本才裝得上去。

**0.9.1.5 以前的版本**：App 內更新裝不起來，請手動下載最新版安裝一次，之後就能在 App 裡直接更新。

## 免費開放到 2026/12/31

Luma 所有功能免費開放到 **2026 年 12 月 31 日**（台灣時間）。之後想繼續使用：

- 在 Luma 裡按「聯絡我」，或直接到 Threads 私訊 [@i__wade](https://www.threads.com/@i__wade)。
- 收到開通碼後，在 Luma 裡按「輸入開通碼」貼上，就會永久開通，不需要連網。

不想繼續用的話，按「換回原本的桌面」，選回手機原本的桌面即可。

## 換手機或重灌

「設定」首頁有「備份設定」和「還原設定」。備份檔會存到「下載」資料夾，裝好 Luma 後還原，桌面和設定都會回來；開通碼需要重新輸入一次。

0.9.1.3 起 Luma 換成新的 app（`com.luma.launcher`），舊測試版無法直接升級，要另外安裝新版。
